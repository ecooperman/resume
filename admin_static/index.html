People

Each person's resume lives here - never a file, never in git. The default person is who the public site above and the time-management app's default resume generation both use.

Generate a resume.yaml from documents

Don't want to hand-write YAML? Upload a LinkedIn profile export (from the job-application Chrome extension's "Export LinkedIn profile" button, on your own linkedin.com/in/ page) and/or any other documents you have - old resumes as PDF/DOCX, LinkedIn's own "Get a copy of your data" export, plain text notes - and Claude will draft a resume.yaml from them into the form below for you to review and edit before adding. See README.md's "Constructing your resume.yaml" section for more on what to feed it. This can take 20-60 seconds.

Access codes

A code is tied to one specific person, chosen below, and unlocks their full resume (contact info + real downloads) at resume.evancooperman.com - the code itself is enough, no other link parameters needed. To browse someone else's redacted public version without a code, add ?person=<slug> to the link instead.
